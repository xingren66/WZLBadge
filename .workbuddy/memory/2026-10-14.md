# 2026-10-14

## WZLBadge：为 wzl_badge 增加容器视图，适配 iOS 26 UIBarButtonItem customView

背景问题：iOS 26 起 UINavigationBar 会给 `UIBarButtonItem.customView` 自动加玻璃背景，
并按导航栏背景对 customView 内子视图混色，导致挂在 customView 上的 `wzl_badge`(UILabel)
背景色被导航栏背景影响。

改动（视图层级由 `self -> UILabel` 变为 `self -> wzl_badgeContainer(UIView) -> UILabel`）：
- `WZLBadge/Protocol/WZLBadgeProtocol.h`：新增 runtime key `badgeContainerKey`。
- `WZLBadge/View/UIView+WZLBadge.m`：
  - 新增私有容器 `wzl_badgeContainer`（associated object），且 `backgroundColor = clearColor`、
    `opaque = NO`、`clipsToBounds = NO`、`userInteractionEnabled = NO`（不吞掉 bar item 点击）。
  - 新增私有布局方法 `-wzl_setupBadgeContainerWithFrame:` / `-wzl_badgeFrameInSuperview` /
    `-wzl_setBadgeFrame:` / `-wzl_setBadgeCenter:` / `-wzl_setBadgeHidden:`；
    label 始终填满容器（frame = container.bounds），容器 frame 语义 == 原来 label 在 self 坐标系里的 frame。
  - `wzl_badgeInit`、`wzl_showNewBadge`、`wzl_showNumberBadgeWithValue:`、`wzl_resetBadgeForRedDot`、
    `setWzl_badgeFrame:`、`setWzl_badgeCenterOffset:`、`wzl_clearBadge`/`wzl_resumeBadge` 全部改走上述方法。
  - `setWzl_badge:` 会把外部传入的 label 重新挂到容器上。
  - 公开 API（`wzl_badge` 仍返回 UILabel）与协议未变，向后兼容。
- `WZLBadge/View/UIView+WZLBadge.h`：补充 iOS 26 说明，并提示可配合
  `UIBarButtonItem.hidesSharedBackground = YES`（iOS 26 API）去掉整个 item 的玻璃背景。
- 顺手修复既有潜在崩溃：`UIBarButtonItem+WZLBadge.m` / `UITabBarItem+WZLBadge.m`
  未转发协议中的 `wzl_badgeRadius`（原先 `barItem.wzl_badgeRadius = x` 会 unrecognized selector）。

验证：Xcode 26.3 / iphonesimulator26.2 编译通过，本工程源码零告警（仅剩 pbxproj 里
CFBundleIdentifier 与 PRODUCT_BUNDLE_IDENTIFIER 不一致的历史告警）。
编译需加 `-derivedDataPath ./.derivedData`，否则沙箱会拦截 Library/Developer/Xcode/DerivedData 写入。
